iPhoneでオレンジのアイコンにする手順

所要 約15分／費用 0円／このフォルダのファイルをそのまま使います

なぜいまアイコンが灰色なのか

安
いま（灰色）
こうしたい

Apps Script のURL（script.google.com/…/exec）を開くと、 いちばん外側のページはGoogleが用意したもので、私たちの画面はその内側の枠に表示されます。

iPhoneはいちばん外側のページからアイコンを読みます。 そこはGoogleのページなのでアイコンの指定がなく、 iPhoneがタイトルの「安否確認…」から「安」の1文字で灰色のアイコンを自動生成しています。

これは Apps Script のままでは直せません。 外側のページはGoogleのものなので、こちらから書き換えられないためです。
ページを自分たちの置き場所に置けば、指定どおりのアイコンになります。
Android用のアプリ（APK）は、すでにオレンジのアイコンです。 灰色になるのは、URLからホーム画面に追加した場合だけです。

圏外で開けるようになるのが、実はいちばん大きい変化です。 災害時は電波が弱くなります。いまのURL方式だと、iPhoneの方はアプリが開けません。 置き場所を作れば、一度開いておけば圏外でも開けます（Android版APKと同じになります）。

1GitHubの無料アカウントを作る

  1. github.com/signup を開く
  2. メールアドレス（anpi.keiline@gmail.com がおすすめ）・パスワード・ユーザー名を入れる
    ユーザー名は英数字で。あとでURLに使われます（例 anpi-kline）
  3. メールに届いた数字を入れて完了

※ 無料プランでよいです。有料の案内が出ても選ばないでください。
※ クレジットカードの登録は不要です。

GitHubは、世界中の会社が使っているファイルの置き場所です。 プログラムを書く人向けのサービスですが、ファイルを置くだけなら難しくありません。 今回は「ドラッグして置く」だけで終わります。

2置き場所を作る

  1. 右上の ＋ → New repository（新しいリポジトリ）
  2. Repository name に anpi と入れる
  3. Public（公開）を選ぶ
    ※ 置くファイルに個人情報は入っていません。名簿はGoogle側にあります
  4. Create repository を押す
Public（公開）で問題ない理由。 ここに置くのは画面の見た目と、倉庫のURLと、担当者3名の電話番号だけです。 300人の名簿・回答・氏名はすべてGoogleスプレッドシート側にあり、 合いことばがないと取り出せません。
担当者の携帯番号が気になる場合は、contacts.json の番号を 090-XXXX-XXXX のように伏せてからアップロードしてください。 アプリは起動時に倉庫から本物の番号を取りに行くので、実際の動作は変わりません。

3ファイルを置く

GitHubが日本語表示のときの押す場所。
できた画面の青い枠の中に、こう書かれた1行があります。
新しいファイルを作成するか、既存のファイルをアップロードして始めましょう。
下線の 「既存のファイルをアップロード」 を押してください。
※ 見つからないときは、上の コード タブ → ファイルの追加（Add file）→ ファイルをアップロード（Upload files）でも同じ画面になります。
  1. 青い枠の 「既存のファイルをアップロード」 を押す
  2. エクスプローラーで 公開用_GitHubPages フォルダを開く
  3. Ctrl+A で全部選ぶ → ★アップロード手順.html を Ctrl+クリックで外す
    （12個が選ばれた状態になります）
  4. 選んだファイルを、GitHubの枠の中にドラッグして落とす
  5. 下まで進んで 変更をコミット（Commit changes）を押す

※ 手順書もいっしょに上げてしまっても、動作に問題はありません。 　 中に合いことばなどは入っていません。

4公開する

  1. 上の 舞台設定（Settings・歯車マーク）を押す
  2. 左のメニューから Pages（ページ）を押す
  3. Source（ソース）を Deploy from a branch（ブランチからデプロイ）にする
  4. Branch（ブランチ）を main、フォルダは / (root) にして Save（保存）
  5. 1〜2分待って、同じ画面を再読み込みするとURLが表示されます

URLはこうなります（ユーザー名は anpi-kline で作成済みです）。

使う人URL
スタッフ（300人）https://anpi-kline.github.io/anpi/
上司5人https://anpi-kline.github.io/anpi/admin.html

5ホーム画面に追加する

  • iPhone：Safari で開く → 下の共有ボタン（↑）→「ホーム画面に追加」
  • Android：Chrome で開く → 右上の ︙ →「ホーム画面に追加」

オレンジのアイコンが出れば成功です。 タップすると全画面で開き、一度開いたあとは圏外でも開けます。

灰色のアイコンが残っている場合。 前に追加したものは、長押しして削除してから、新しいURLで追加し直してください。 iPhoneは追加したときのアイコンを覚え続けるためです。

6あとで中身を直したいとき

GitHubの画面で Add file → Upload files から、同じ名前のファイルを上げ直すだけです。 1〜2分で反映されます。

スタッフのスマホに反映させるには、sw.js の番号も1つ増やしてください。
const CACHE = 'anpi-v3' → 'anpi-v4'
圏外用に保存したファイルを使い続けるため、この番号を変えないと古い画面が出ます。

補足Apps ScriptのURLはどうなる？

そのまま残しておいてください。捨てる必要はありません。

役割
GitHub Pages の2つのURL人が開く画面（アイコン・全画面・圏外対応）
Apps Script の /execデータの受け渡し（回答の記録・電話番号・状況）

役割が分かれるだけで、スプレッドシートも名簿も回答も、いまのまま変わりません。 Android版のAPKも作り直し不要です。

ここまでやるのが大変なら、無理に急ぐ必要はありません。 いまのApps ScriptのURLでも報告機能は完全に動きます（アイコンが灰色で、圏外では開けないだけです）。 Androidのスタッフはすでにオレンジのアイコンで、圏外でも開けます。
iPhoneの方が多い、または圏外対応を重視するなら、この手順をやる価値があります。
